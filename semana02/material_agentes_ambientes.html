🧮 Quadro-negro — o agente como função

Formalmente, um agente é uma função que mapeia histórias de percepções em ações:

f : P* → A

P* = sequência de percepções. A = conjunto de ações. O programa do agente implementa f.

E um agente racional é aquele que, para cada história de percepções, escolhe a ação que maximiza o valor esperado da medida de desempenho:

ação* = argmaxa ∈ A 𝔼[ desempenho | história, a ]

Esta equação é a mesma da semana 1. A novidade agora é que vamos calcular esse argmax — por busca (S3–5), por gradiente (S8–9) ou por experiência (S10–14).

⚠️ Armadilha
  • "Ambiente = mundo físico." Ambiente é uma abstração: pode ser um tabuleiro, um dataset, uma API, um simulador. O que importa é a interface reset()/step().

4 · Código do zero: GridWorld em Python + NumPy

O GridWorld que você implementar agora será o ambiente das semanas 10–14. Cada decisão de design importa:

4.1 GridWorld como classe Python

# gridworld.py — o ambiente que nos acompanhará até a Semana 16
import numpy as np

class GridWorld:
    def __init__(self, tamanho=4):
        self.tamanho = tamanho
        self.agente_pos = np.array([0, 0])        # estado: posição (x,y)
        self.objetivo = np.array([tamanho-1, tamanho-1])  # canto oposto
        self.obstaculos = [(1,1), (2,2)]            # paredes (não pode entrar)
        self.done = False
        self.recompensa_acumulada = 0.0

    def reset(self):
        self.agente_pos = np.array([0, 0])
        self.done = False
        self.recompensa_acumulada = 0.0
        return tuple(self.agente_pos)  # observação = posição

    def step(self, acao):
        # ações: 0=↑, 1=↓, 2=←, 3=→
        movimentos = {0: (-1,0), 1: (1,0), 2: (0,-1), 3: (0,1)}
        delta = np.array(movimentos[acao])
        nova_pos = self.agente_pos + delta

        # Validação: não sair da grade, não entrar em obstáculo
        if (0 <= nova_pos[0] < self.tamanho and
            0 <= nova_pos[1] < self.tamanho and
            tuple(nova_pos) not in self.obstaculos):
            self.agente_pos = nova_pos

        # Recompensa: +1 no objetivo, -0.01 por passo (eficiência)
        if np.array_equal(self.agente_pos, self.objetivo):
            recompensa = 1.0
            self.done = True
        else:
            recompensa = -0.01

        self.recompensa_acumulada += recompensa
        return tuple(self.agente_pos), recompensa, self.done

4.2 Agente reativo simples para o GridWorld

def agente_reativo(obs):
    """Agente reativo simples: sempre move na direção do objetivo.
       Não tem memória, não planeja, não aprende."""
    x, y = obs
    obj_x, obj_y = 3, 3  # posição do objetivo (conhecida a priori)

    if x < obj_x:   return 1  # ↓ (aumenta x)
    if x > obj_x:   return 0  # ↑ (diminui x)
    if y < obj_y:   return 3  # → (aumenta y)
    if y > obj_y:   return 2  # ← (diminui y)
    return 0  # parado no objetivo
⚠️ Por que este agente falha?

O agente reativo acima não contorna obstáculos. Se o caminho direto está bloqueado por uma parede em (1,1), ele fica preso tentando ir para baixo e para a direita alternadamente — sem nunca alcançar o objetivo. Para resolver isso, precisamos de busca (Semana 3). Para resolver sem conhecer o mapa, precisamos de reinforcement learning (Semana 10).

4.3 O ciclo principal — idêntico ao que usaremos até a S16

env = GridWorld(tamanho=4)
obs = env.reset()
for t in range(100):
    acao = agente_reativo(obs)
    obs, recompensa, done = env.step(acao)
    print(f"t={t:3d}  pos={obs}  r={recompensa:+.2f}  total={env.recompensa_acumulada:+.2f}")
    if done:
        print(f"Objetivo alcançado em {t+1} passos!")
        break

5.1 O essencial de NumPy em 3 atos

# Ato 1 — Arrays e operações elemento a elemento
import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([5, 6, 7, 8])
a + b        # → array([ 6,  8, 10, 12]) — sem laço!
a * b        # → array([ 5, 12, 21, 32])

# Ato 2 — Broadcasting: operações entre arrays de dimensões diferentes
Q = np.zeros((4, 4, 4))           # 16 estados × 4 ações = tabela Q
recompensas = np.array([0, -0.01, -0.01, -0.01])  # vetor de recompensas por ação
Q[0, 0] += recompensas             # broadcasting automático

# Ato 3 — Indexação booleana e argmax (coração do RL)
valores = Q[0, 0]                   # valores Q para o estado (0,0)
melhor_acao = np.argmax(valores)    # ação com maior valor esperado
print(f"No estado (0,0), melhor ação é {melhor_acao}")
