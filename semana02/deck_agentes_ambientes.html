O que muda a cada módulo é apenas o que acontece dentro de decidir().

6 propriedades que decidem a técnica

1. Observável vs Parcialmente obs.
Sensores veem tudo? GridWorld: sim. Poker: não. → estado interno (S2).
2. Determinístico vs Estocástico
Mesma ação = mesmo resultado? Se não: probabilidade (S7).
3. Episódico vs Sequencial
Decisões independentes ou encadeadas? Sequencial → MDPs (S10–14).
4. Estático vs Dinâmico
Mundo muda enquanto pensa? Dinâmico → anytime algorithms.
5. Discreto vs Contínuo
Estados enumeráveis? Contínuo → aproximação (S14).
6. Agente único vs Multiagente
Outros decidem também? → teoria dos jogos (S5).

NumPy e GridWorld

Arrays · Broadcasting · Vetorização · Implementação do zero

Por que NumPy?

Sem NumPy

# laço for: 50 ms para 1M elementos
c = []
for i in range(len(a)):
    c.append(a[i] + b[i])

Com NumPy

# vetorizado: 0.1 ms para 1M elementos
c = np.array(a) + np.array(b)

500× mais rápido. A diferença entre rodar em 1 segundo e rodar em 8 minutos.

NumPy é a interface entre o Python e a álgebra linear que move a IA moderna. Todo o RL deste curso depende dele.

NumPy em 3 atos

# Ato 1: Arrays e operações elemento a elemento
a = np.array([1, 2, 3]); b = np.array([4, 5, 6])
a + b # → array([5, 7, 9]) — sem laço

# Ato 2: Broadcasting — arrays de dimensões diferentes
Q = np.zeros((16, 4)) # tabela Q: 16 estados × 4 ações
Q[0] += np.array([0, -0.01, -0.01, -0.01]) # broadcasting!

GridWorld — implementação do zero

class GridWorld:   def __init__(self, tamanho=4):     self.pos = np.array([0, 0])     self.objetivo = np.array([tamanho-1]*2)     self.obstaculos = [(1,1), (2,2)]   def reset(self):     self.pos = np.array([0, 0])     return tuple(self.pos)   def step(self, acao): # 0=↑ 1=↓ 2=← 3=→     mov = {0:(-1,0),1:(1,0),2:(0,-1),3:(0,1)}     nova = self.pos + mov[acao]     if 0<=nova[0]<self.tamanho and 0<=nova[1]<self.tamanho:       if tuple(nova) not in self.obstaculos:         self.pos = nova     if np.array_equal(self.pos, self.objetivo):       return tuple(self.pos), 1.0, True     return tuple(self.pos), -0.01, False

Este GridWorld será o ambiente das Semanas 10–14. O que você escrever hoje treinará um agente de RL daqui a 8 semanas.
