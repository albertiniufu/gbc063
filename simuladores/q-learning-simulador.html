Q-Learning, um passo de cada vez

Um agente aprende a atravessar uma grade 4×4 até o tesouro sem cair nos buracos. Cada clique executa exatamente uma linha do pseudocódigo — e você vê a tabela Q mudar por causa dela.

episódio 0/150 t = 0 ε = 1.00 retorno do episódio 0.0

Mundo em grade · tabela Q

pronto A tabela Q começa zerada: o agente não sabe nada. Toque em “Executar próxima linha” para começar.

Controles

Quanto do erro de TD é incorporado a cada atualização.
Quanto vale uma recompensa futura comparada a uma imediata.
Probabilidade de explorar. Cai 5% por episódio (condição GLIE), com piso de 0,02.

Pseudocódigo ao vivo

Entrada: política π, num_episodes, fração α, GLIE {εi} Saída: função valor Q (≈ qπ) Inicialize Q (Q(s,a) = 0, Q(terminal,·) = 0)passo 1 para i ← 1 até num_episodes faça ε ← εi Observe S0 t ← 0 repita Escolha At com política derivada de Q (ε-greedy)passo 2 Execute At e observe Rt+1, St+1passo 3 Q(St,At) ← Q(St,At) + α(Rt+1 + γ maxa Q(St+1,a) − Q(St,At))passo 4 t ← t + 1 até St ser terminal; fim retorne Q
